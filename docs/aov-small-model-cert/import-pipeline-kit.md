## 流程 scope（原文）

描述兩種建立匯入工作入口、狀態與錯誤查詢、提交及取消。兩種建立入口互為替代；連線只表示各自回傳的工作識別碼可用於狀態查詢，不要求同時執行。狀態查詢為共用能力，不綁定建立方式。提交節點包含 ImportService.commit_job 的持久化能力，只接受 READY／COMMITTING；不表示建立後可立即提交，也不強制先查詢錯誤或狀態。未涵蓋無獨立登錄能力的暫存列驗證、背景處理各分支及跨 Kit 上傳流程。尚未完成執行驗證。
