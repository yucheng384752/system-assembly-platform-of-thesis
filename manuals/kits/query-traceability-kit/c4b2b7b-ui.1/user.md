## 用途

以批號查詢站點紀錄，或檢視同一批號的追溯路徑。

## 前置條件

準備要查詢的批號。空白批號不會送出查詢。

## 可設定項目

畫面可切換「批號查詢」與「追溯路徑」，並輸入批號。

## 操作步驟

1. 開啟「資料查詢」，選擇查詢模式。
2. 輸入批號，按「查詢」或 Enter。
3. 查詢期間等待「查詢中」結束。
4. 檢視各站點紀錄；欄位超過前四項時，可按展開按鈕查看更多。

## 輸入輸出

輸入批號；查詢結果顯示站點名稱、紀錄筆數、批號與欄位內容。追溯結果依深度排列；沒有結果時顯示「查無資料」。

## 常見錯誤與復原

查詢失敗時畫面顯示錯誤訊息。可重新輸入批號再按查詢；伺服器資料修復程序尚未提供。
