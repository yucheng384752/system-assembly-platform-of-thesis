## 用途

在「檔案上傳」頁先預覽 CSV 的檢查結果，確認後才把資料寫入表單。預覽不會寫入任何資料。

## 前置條件

需先在「通用表格」建立表單並儲存欄位定義。沒有任何已定義欄位的表單時，頁面只顯示提示「請先到『通用表格』建立表單與欄位」，無法選檔。

## 可設定項目

只有兩項：選擇表單、選擇 CSV 檔。CSV 第一列為欄名，欄名須與欄位定義中的「CSV 對應欄位」相符；對應欄位留空時，欄名須與欄位名稱相同。

## 操作步驟

1. 開啟「檔案上傳」，在「表單」下拉選擇表單。
2. 在「CSV 檔案」選擇檔案，按「預覽檢查」。
3. 閱讀摘要，例如「共 3 筆：可匯入 2 筆，重複 0 筆，有錯誤 1 筆」。下方只列出可匯入的資料列，最多 10 列。
4. 有錯誤時，錯誤清單會以資料列序號說明原因，例如「第 2 列：'數量' 的值「abc」不是有效的整數」。錯誤列不會被匯入；可修正檔案後重新預覽，或直接匯入其餘的列。
5. 按「匯入 N 筆」。完成後顯示「匯入完成：新增 2 筆，略過重複 0 筆，錯誤 1 筆未匯入」。

## 輸入輸出

輸入為一個 CSV 檔與一張表單。列序號指資料列，不含欄名那一列。預覽表格的欄名是欄位名稱，不是 CSV 欄名。相同識別鍵的列視為重複：預覽只計入「重複」筆數，不出現在預覽表格；匯入時略過。對同一個檔案再次預覽，結果會是「可匯入 0 筆，重複 2 筆」，匯入按鈕顯示「匯入 0 筆」，並提示「沒有可匯入的資料」。

## 常見錯誤與復原

- 數值、日期等型別不符時，訊息以「整數、數值、是否、日期」說明，並指出列序號與欄位。請改正檔案後重新預覽。
- 只有欄名、沒有資料列的檔案，預覽會顯示 0 筆，且沒有額外說明；請確認檔案內有資料列。
- 預覽之後尚未按匯入前，系統內沒有任何變動，直接離開即可。已匯入的資料需到「通用表格」的「紀錄查詢」逐筆編輯或刪除；整批復原尚未提供。
